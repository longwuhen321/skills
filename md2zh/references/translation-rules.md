# 翻译规则

## 内容边界

翻译读者可见的自然语言：

- ATX 与 Setext 标题文本；
- 段落、列表项文本、引用块与表格单元格内容；
- 强调标记与普通行内 HTML 元素内的文本；
- 行内链接标签与图片替代文本；
- 脚注文本及其周围的引用文字。

以下源内容保持原样：

- 围栏与缩进代码块、行内代码及类代码的 HTML 元素；
- `$...$`、`$$...$$`、`\(...\)` 与 `\[...\]` 内的 LaTeX；
- 链接目标、图片路径、裸 URL、自动链接、引用标识符、引文键与脚注标识符；
- Markdown 标记、缩进、硬换行空白、空行与行尾符；
- YAML frontmatter、HTML 标签与属性、注释、实体、转义与模板语法；
- 正式书目标题与元数据。

引用式快捷标签同样是标识符，保持原样。仅当引用标识符被单独保护时，才翻译完整/折叠引用链接的标签文本。

pipeline 用 ASCII `@@MD2ZH:PROTECT:...@@` 标记表示受保护的源内容。每个提供的标记恰好保留一次。标记可随中文自然语序移动，但不得拆散格式配对。绝不发明、修改、复制或遗漏任何标记。

面向模型的输入是一组完整的翻译块，而非数百条 JSON 映射。每个 `@@MD2ZH:SEG:block-....:....@@` 行开始一个翻译段；一段可跨多个物理行（段落级单元）。逐行原样保留每个段行且顺序不变。只翻译内容——段内可自由重排、调整换行与断句（物理行数不受限），但不得引入空行（包括只含空格或 Tab 的行）、行首或行尾换行，或任何以块级标记（0–3 个空格后的 `#`、`>`、`-`、`+`、`*`、有序列表，以及四空格/Tab 缩进代码）开头的行。不要在段外添加包装、注释或多余行。

## 模糊内容

读取 skill 级配置（`<skill-directory>/scripts/config.py`，键 `ambiguous_content_decider`）以确定模糊内容由用户还是 AI 助手决定。translate 决策必须选择 pipeline 建议载荷内的精确源子串；它绝不授权重写整个未知结构。

对于 AI 助手决策，使用所提供的完整章节与相邻上下文，并记录简明理由。`decisions.json` 必须恰好覆盖每个 region ID 一次；translate 决策按 `record-decisions` 输出的 `extra_translations_skeleton` 填写译文，并在 `merge-blocks` 时通过 `--extra-translations` 传入。让 pipeline 将全部 accepted、rejected 与 retried 决策持久化到 `<skill-directory>/logs/decision_logs/*.jsonl`，供后续诊断与规则改进。

## 翻译质量

- 保持含义、范围、语气、逻辑关系与确定性不变。不增、不减、不概括、不加个人评论。
- 优先使用自然简体中文，而非照搬英文语序。
- 使用公认的中文技术术语，并保持各章节间术语一致。
- 准确保留人名、产品名、命令、标识符、变量、书目元数据、DOI、ISBN、URL 与引文键。
- 先通读全部块一次，建立文档上下文与共享术语表，再按源顺序翻译。绝不因安全 pipeline 将内容行单独存储，就把它当作无上下文的内容。
- 正式引用文献标题保持源语言，除非文档一贯使用公认的中文标题。
- 独立翻译表格单元格，不改变其周围的竖线与空白。

## 术语表持久化

- 每个任务开始时读取 state 指向的 `glossary.json`；单文件默认位于任务根，树形翻译的所有文件必须指向同一份树级术语表。
- 文件格式固定为 `{"schema_version": 1, "terms": {"源术语": "统一译法"}}`。只保存术语映射，不写文档正文、凭据或会话信息。
- 新术语先写入增量 JSON，再通过 `update-glossary <state.json> <增量.json>` 合并。既有术语译法冲突时默认停下复核，不静默覆盖；完成复核后才使用 `--replace`。
- 每个新块和树内每个新文件开始前重新读取术语表；`cleanup-run` 将当前术语表快照随任务归档。

## 语义复核

复核全部已翻译块，检查遗漏、重复、误译、确定性改变、术语漂移、未翻译的英文文本与不自然的中文。对长文档，复核每个标题、每个表格、每次模糊内容决策、公式与图表周围的文字、引言、结尾部分，以及每个一级标题下的至少一个完整段落。
