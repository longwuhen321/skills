# md2zh — Markdown 翻译为中文

将用户指定的英文 Markdown 文件翻译为中文，输出为新文件（在原文件名后添加 `_zh` 后缀）。

## 执行流程

### 1. 读取原文

如果用户未指定文件路径，询问用户要翻译哪个文件。读取目标 `.md` 文件，通读全文理解语境后再开始翻译。

### 2. 翻译规则

**必须保留不翻译的内容：**

- 代码块（`` ``` `` 包裹的内容）——代码本身不动，仅翻译代码块外的描述文字和代码块内的注释（`//`、`#`、`/* */` 后的内容）
- LaTeX 数学公式（`$...$` 或 `$$...$$` 包裹的内容）
- URL 链接地址（`[text](url)` 中的 `url` 部分）和所有以 `http`、`//` 开头的链接
- 图片引用路径（`![alt](path)` 中的 `path` 部分）
- 引用标注（`[n]`、`[[n]](#cite_note-xx)`、`[↑](#cite_ref-xx)` 等）
- 维基百科模板标记（如 `{{cite journal}}`、`{{cite web}}` 等）
- 专有名词/人名/品牌名/产品名（如 Simulink、MATLAB、FPGA、Wikipedia 等）

**需要翻译的内容：**

- 段落文字、标题、表格内容
- 图片的 alt 文本（`![中文描述](path)`）
- 链接的显示文本（`[中文文本](url)`）
- 列表项、引用块内容
- Wikipedia 维护模板中的说明文字

**翻译原则：**

- **先通读后翻译**：翻译每个段落前，理解其在整个文档中的位置和上下文
- **术语一致性**：同一英文术语在全文中的翻译保持一致。翻译前先扫描全文高频术语，建立术语映射表
- **技术准确性**：对技术内容，使用该领域公认的中文术语，而非字面直译
- **流畅可读**：中文表达应符合中文阅读习惯，避免"翻译腔"
- **保持原意**：不添加、不删减、不歪曲原文含义
- **保留语气**：Wikipedia 的提示框、警告框等维护性文字保持与原文学术/百科的语气一致

**术语参考来源：**

翻译技术术语时，优先参考以下权威来源，确保术语与国家标准一致：

- 全国科学技术名词审定委员会《自动化名词》：http://cnterm.cn/sd/xxjs/zwh/zdh/
- 全国科学技术名词审定委员会《自动化科学技术名词》第二版（2025）：http://cnterm.cn/news/tzgg/202503/t20250306_762373.html
- GB/T 2900.56-2008《电工术语 控制技术》（等同 IEC 60050-351:2006）：https://www.guifanku.com/916794.html

> 如文档涉及其他领域（机械、电子、化工、医学等），请自行查找对应学科的审定名词或国家标准。全国科学技术名词审定委员会官网 (http://cnterm.cn) 覆盖所有学科。

### 3. 输出文件

- 输出路径：在原文件同目录下，文件名改为 `原文件名_zh.md`
- 保持原文件的换行风格和缩进
- 如原文有 `> 原文链接:` 行，保留不动并在其下方添加翻译标注

### 4. 翻译后校验

翻译完成后，执行以下校验步骤：

1. **结构校验**：对比原文和译文的标题数量、表格行数、代码块数量、图片数量、链接数量。如有差异，找出原因并修复
2. **内容抽查**：随机抽取 3–5 个段落，对比原文和译文，确认：
   - 含义准确，无增删歪曲
   - 术语使用一致
   - 中文表达自然流畅
3. **格式检查**：确认代码块、LaTeX 公式、链接、表格格式完整无损
4. **报告结果**：向用户报告校验结果（匹配/不匹配项及修复情况）
