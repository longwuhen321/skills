# Markdown 导入预审规则

仅在最终生效的 `preflight_review` 为 `true` 时完整读取本文件。关闭预审时不读取。

## 执行契约

1. 在任何页面或附件写入前预审本次任务的全部 Markdown。
2. 保持源文件字节不变；生成 UTF-8 `candidate.md`，只把该副本交给正文转换。
3. 始终以源 Markdown 所在目录解析附件，不能以副本目录解析相对路径。
4. 把 `candidate.md`、`review.json` 和 `manifest.json` 放入
   `<skill>/logs/intermediate/<时间戳>/<任务标识>/`；成功后移入 `logs/_archive/`，
   失败时保留 intermediate 产物供排查。
5. 单页预审失败或树中任一页面预审失败时，禁止执行任何远端写入。

## 阻断规则

- 拒绝非 UTF-8、NUL 字符和内部占位符残留。
- 拒绝无法安全识别或未配对的 `$...$`、`$$...$$` 和 `latex` 围栏。
- 拒绝公式内明显不平衡的花括号和不配对的 `\begin{...}` / `\end{...}`。
- 拒绝不存在的本地附件；HTTP、协议相对、`data:` 和页内引用不作本地检查。
- 拒绝转换后不平衡的 storage XHTML。
- 拒绝公式数量与 `mathinline` / `mathblock` 宏数量不一致。
- 拒绝转换后仍有正文公式、内部占位符或数学宏内 `em` 标签残留。

## 确定性修复

- 把对称空格行内公式 `$ x $` 规范化为 `$x$`。
- 单边空格公式仅在内容具有强数学特征时修复，包括 LaTeX 命令、上下标或两侧有操作数的算术运算；只修改 `candidate.md`。`$ x$`、`$x $` 等含义不明确的写法继续阻断，避免误伤 shell 变量和金额。
- 把明确位于公式内部的 `<em>...</em>` 恢复为 LaTeX 下划线。
- 把未定义控制序列 `\*` 规范化为 `*`。
- 不猜测未知 LaTeX 命令，不改写公式语义。

## 审核报告

读取失败报告时按 `规则 ID + 行列 + 消息` 定位。只有全部阻断项通过，且
`storage_validation.passed=true`，才允许继续上传。不要通过忽略报告或直接改
manifest 绕过门禁；需要绕过整套预审时，必须由用户显式关闭配置或使用 CLI 覆盖。
