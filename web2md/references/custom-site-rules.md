# 非平台结构页面规则（自定义站点）

## 强制读取条件

脚本报告“检测到裸 TeX 定界符”、“REVIEW”或“段落切碎检测”时，
**必须在修复与收尾前完整读取本文件**。未命中这些特征时不读取。

本文件只描述通用模式，不写具体站点；真实案例仅在排查问题时查阅
`../KNOWN_ISSUES.md`。

## 1. 特征清单（检测表）

「非平台结构页面」指 HTML 不由框架（MediaWiki / Sphinx / GitBook / VitePress 等）生成的
自定义站点。检测命中任意一项即走本章流程：

| 特征 | 检测方式 | 说明 |
|------|----------|------|
| 公式为裸 TeX 定界符 | 脚本报告「检测到裸 TeX 定界符: 行内 N，显示 N」 | KaTeX auto-render / MathJax tex2jax：公式是文本节点里的 `\(...\)` / `\[...\]`，无 `<math>` / `class="math"` / `<script type="math/tex">` 等机器可读标记 |
| 跨节点 REVIEW | 脚本报告「REVIEW N 处」 | 同一块内仅跨中性 `<span>`、节点数/长度受限且唯一配对的候选自动转换；跨块、保护子树、格式标签、HTML 注释/Doctype 等非正文节点或歧义候选保持原文 |
| 段落切碎 | 脚本报告「段落切碎检测: N/M 段 ≥50%」 | HTML 源码硬换行（每行 ~90 字符）被 markdownify 保留，自然段切成 2-6 行 |
| 混合定界符 | 页面同时出现 `\[...\]` 与 `$$...$$` | 脚本自动处理两种；`$$...$$` 为页面自带，已合法 |
| 无平台特征 | 非 Sphinx/GitBook/Wiki 判定 | meta[generator] 无框架标记，结构自定义 |

## 2. 裸 TeX 定界符转换规则

脚本 `convert_plain_tex_delimiters` 已自动执行（`process_math_formulas` 之后，DOM
文本节点级，跳过 code/pre/script/style/math 子树）：

- `\(...\)` → `$...$`（行内）；`\[...\]` → `$$...$$`（显示，`$$` 独占一行由转换管道兜底）
- **表格单元格行内化**（`table_formula_inline` 开启，默认）：`<td>`/`<th>` 内的 `\[...\]` → `$...$`
  （行内）——markdown 表格单元格无法容纳 `$$` 块（独占行 + 空行撕裂表格），行内定界符让
  公式留在单元格内；含 `\\` 行断的多行公式在单元格内不换行（inline 模式 `\\` 无效），
  **由 AI 复核时改写为 `$\begin{aligned} ... \end{aligned}$`**（单物理行内 `\\` 换行、`&` 对齐；
  外层跨行括号改手动大小 `\Bigg( ... \Bigg)`——`\left...\right` 必须同行成对，跨行渲染失败）
- **保护项**（脚本已处理，复核时确认）：
  - `\\[0.5em]` 矩阵行距（开定界符前一个字符是反斜杠）
  - `\left(` `\left[`（反斜杠不在括号前，天然不匹配，无需担心）
  - `\\)` / `\\]` 转义序列
- **`\]` 后粘连正文**（`\]where:`）：脚本替换后 `$$where:` 会被 `$$` 独占机制拆行；
  复核时确认正文未与公式块粘连
- **跨节点配对**：脚本只自动处理同一块边界内、最多 12 个文本节点和 2000 字符、仅跨
  中性 `<span>` 且下一定界符唯一匹配的候选；`code/pre/script/style/math` 保护子树、`<i>` / `<em>`
  等格式标签、Comment/Doctype/声明等非正文节点、跨块、歧义或超限候选保持原文并报告 `REVIEW`。AI 助手需通读定位并手工修复，
  不得为清零计数而猜测定界符

### 扩展兼容的通用排查法

公式不渲染时按此排查（不穷举宏包，按模式处理）：

1. 公式用到的宏是否在 MathJax base 之外（如 `\xcancel`、`\cancel` 属 cancel 扩展）
2. 在公式头加 `\require{<扩展名>}`（如 `\require{cancel}`）——已加载时是无害空操作
3. 仍不渲染则改为语义等价的 LaTeX 或保留原始 TeX 文本，在轮次清单记录

## 3. 处理流程

1. **脚本自动**：转换 + 诊断输出（可靠裸定界符计数、不可靠候选 REVIEW、段落切碎率）
2. **AI 复核**（核心纪律：脚本只做机械操作，AI 全量审核）：
   - 通读 .md，验证每个自动转换的公式渲染正确（含 `\require` 类兼容项）
   - 修复跨节点 REVIEW 项，写进轮次清单 `fix_list_roundN.md`
   - 按本文件 §2 的排查法处理不渲染的公式
3. **段落合并**（可选，通用能力，见 SKILL.md 第五步）：
   切碎检测命中或用户偏好时启用 `--merge-paragraphs` / config `merge_paragraphs`
4. **收尾**：fix_escapes → list_display_fixes → 通读 → final_verify 全绿（FAIL 与
   REVIEW 均为零）
