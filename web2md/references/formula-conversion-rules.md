## 1. 伪公式模式（斜体/粗体 → LaTeX）

### 1.1 A. 斜体 + 数字 → 下标或上标

| 原文 | 修复 | 说明 |
|------|------|------|
| `*a*1` | `$a_{1}$` | 斜体字母+数字 → 下标 |
| `*x*2` | `$x^{2}$` | 需根据上下文判下标还是上标 |
| `*S*3` | `$S^{3}$` | 数学符号+上标 |
| `*r*−1` | `$r^{-1}$` | 变量+幂次 |

### 1.2 B. 斜体 + 运算符 → 行内公式

| 原文 | 修复 | 说明 |
|------|------|------|
| `*x* = *y*` | `$x=y$` | 等式 |
| `*a* + *b*` | `$a+b$` | 加法表达式 |
| `*p* − *q*` | `$p-q$` | 减法表达式 |
| `*c* = *d* = 0` | `$c=d=0$` | 链式等式 |
| `*aq* = *qa*` | `$aq=qa$` | 乘积等式 |

### 1.3 C. 粗体 + 数字 / 运算符 → 向量公式

| 原文 | 修复 | 说明 |
|------|------|------|
| `**i**2` | `$\mathbf{i}^{2}$` | 粗体+上标 |
| `**i** ⋅ **j** = **k**` | `$\mathbf{i}\cdot\mathbf{j}=\mathbf{k}$` | 粗体+运算符 |

### 1.4 D. 粗体字母作为数学符号（散文中）

| 原文 | 修复 | 说明 |
|------|------|------|
| `{1, **i**, **j**, **k**}` | `$\{1,\mathbf{i},\mathbf{j},\mathbf{k}\}$` | 集合 |
| `±**i**, ±**j**, ±**k**` | `$\pm\mathbf{i},\pm\mathbf{j},\pm\mathbf{k}$` | 带正负号 |
| `**i**, **j**, and **k** will denote` | `$\mathbf{i},\mathbf{j},\mathbf{k}$ will denote` | 散文中的符号 |
| `replacing 1 with a, **i** with b` | `replacing $1$ with $a$, $\mathbf{i}$ with $b$` | 映射定义 |

> ⚠️ 乘法表 `| **i** | **j** | **k** |` → **保留 bold**，是表格格式化非公式

### 1.5 E. 函数 + 斜体参数

| 原文 | 修复 | 说明 |
|------|------|------|
| `cos(*φ*)` | `$\cos(\varphi)$` | 三角函数 |
| `sin(*θ*)` | `$\sin(\theta)$` | 同上 |

### 1.6 F. 混合粗体 + 斜体表达式

| 原文 | 修复 | 说明 |
|------|------|------|
| `*a* + *b* **i** + *c* **j** + *d* **k**` | `$a+b\mathbf{i}+c\mathbf{j}+d\mathbf{k}$` | 四元数表达式 |
| `*a*1 + *b*1**i** + *c*1**j**` | `$a_{1}+b_{1}\mathbf{i}+c_{1}\mathbf{j}$` | 带下标表达式 |
| `*p* = *b*1**i** + *c*1**j** + *d*1**k**` | `$p=b_{1}\mathbf{i}+c_{1}\mathbf{j}+d_{1}\mathbf{k}$` | 向量定义 |

### 1.7 G. 斜体含特殊符号（上标星号等）

| 原文 | 修复 | 说明 |
|------|------|------|
| `*pq*∗` | `$pq^{*}$` | 共轭/对偶标记 |
| `*p*∗*q*` | `$p^{*}q$` | 同上 |
| `−*q*∗*p*∗` | `$-q^{*}p^{*}$` | 同上 |

### 1.8 H. 数学符号/记法

| 原文 | 修复 | 说明 |
|------|------|------|
| `*d*g(*p*, *q*)` | `$d_{g}(p,q)$` | 函数+下标+参数 |
| `*r a r*−1` | `$rar^{-1}$` | 共轭表达式 |
| `*p*s, *q*s, *p*v, *q*v` | `$p_{s},q_{s},p_{v},q_{v}$` | 变量+下标 |

## 2. Unicode 符号（I 类）

Wikipedia 用粗体/Unicode 渲染的数学符号，脚本无法识别。出现下列符号时才读对应小节。

### 2.1 I-1. 粗体大写字母（数域/集合记号）— Wikipedia 用 `**X**` 替代黑体板书 `\mathbb{X}`：

| 原文 | 数域 | 修复 |
|------|------|------|
| `**R**` | 实数 | `$\mathbf{R}$` |
| `**C**` | 复数 | `$\mathbf{C}$` |
| `**Z**` | 整数 | `$\mathbf{Z}$` |
| `**Q**` | 有理数 | `$\mathbf{Q}$` |
| `**N**` | 自然数 | `$\mathbf{N}$` |
| `**F**` | 域 | `$\mathbf{F}$` |
| `**H**` | 四元数 | `$\mathbf{H}$` |
| `**U**` | 酉群/算子 | `$\mathbf{U}$` |
| `**O**` | 正交群 | `$\mathbf{O}$` |
| `**S**` | 球面/特殊群 | `$\mathbf{S}$` |
| `M(2,**C**)` | 矩阵环 | `$M(2,\mathbf{C})$` |

### 2.2 I-2. 角度与单位

| 原文 | 修复 | 说明 |
|------|------|------|
| `90°` `180°` `360°` | `$90^{\circ}$` 等 | 角度度数 |
| `45′` `30″` | `$45'$` `$30''$` | 分、秒（罕见） |

### 2.3 I-3. Unicode 运算符

| 原文 | 修复 | 说明 |
|------|------|------|
| `±x` `±i` | `$\pm x$` | 正负号+变量 |
| `a ⋅ b` | `$a \cdot b$` | 点乘 |
| `a × b` | `$a \times b$` | 叉乘（`2 × 2` 维度保留 Unicode） |
| `a ∗ b` | `$a * b$` | 卷积/星乘 |
| `−x` | `$-x$` | Unicode 减号 |

### 2.4 I-4. 不等号与关系符

| 原文 | 修复 |
|------|------|
| `a ≤ b` | `$a \leq b$` |
| `a ≥ b` | `$a \geq b$` |
| `a ≠ b` | `$a \neq b$` |
| `a ≈ b` | `$a \approx b$` |
| `a ≡ b` | `$a \equiv b$` |
| `a ∼ b` | `$a \sim b$` |
| `a ∝ b` | `$a \propto b$` |

### 2.5 I-5. 集合与逻辑符号

| 原文 | 修复 |
|------|------|
| `x ∈ S` | `$x \in S$` |
| `x ∉ S` | `$x \notin S$` |
| `A ⊂ B` | `$A \subset B$` |
| `A ⊆ B` | `$A \subseteq B$` |
| `A ∪ B` | `$A \cup B$` |
| `A ∩ B` | `$A \cap B$` |
| `∀x` | `$\forall x$` |
| `∃x` | `$\exists x$` |

### 2.6 I-6. 箭头

| 原文 | 修复 | 说明 |
|------|------|------|
| `f: A → B` | `$f: A \to B$` | 函数映射 |
| `x ↦ y` | `$x \mapsto y$` | 元素映射 |
| `A ⇒ B` | `$A \Rightarrow B$` | 蕴含 |
| `A ⇔ B` | `$A \Leftrightarrow B$` | 等价 |
| 表头 `→` | 保留 Unicode | 表格格式化 |

### 2.7 I-7. 其他常见符号

| 原文 | 修复 |
|------|------|
| `∞` | `$\infty$` |
| `∂f/∂x` | `$\partial f / \partial x$` |
| `∇f` | `$\nabla f$` |
| `√x` | `$\sqrt{x}$` |

### 2.8 判断边界

与变量/数字/等号紧邻 → 转 `$...$`；维度 `2 × 2`、表格箭头 → 保留。表头 `| **i** |` → 保留。

### 2.9 NBSP 陷阱

Wikipedia 公式常用 `\xa0`（non-breaking space），精确文本匹配时 `**i\xa0⋅\xa0j**` 可能被漏掉，需额外检查。

## 3. Sphinx 页面遗留公式模式

Sphinx 页面（`class="math"` 的 `\(...\)` / `\[...\]`）转换后仍需人工复核以下遗留模式（2026-08-02 起脚本已覆盖纯字母公式，但下列项仍需逐条核对）：

| 模式 | 示例 | 修复 |
|------|------|------|
| 方程编号锚点混入公式块 | `$$` 内 `(5)#\[V = ...\]` | 去掉 `(N)#` 与 `\[` `\]`，保留公式正文；编号信息由正文 `Equation [(N)]` 链接提供 |
| 裸 LaTeX 文本命令（非公式） | `\textsl{streamwise pressure discontinuity}` | 按语义转 Markdown 斜体 `*...*` 或包成 `$...$` |
| `aligned`/`split` 环境内的 `\label` | `k\cdot\sigma^n\label{eq:thrustmodel}\\` | MathJax 3 的 `\label` 仅限编号环境（equation/align/gather），嵌套会报错致公式渲染失败；无对应 `\ref` 时直接删除 |

> 判断边界：`\(...\)` 已由脚本自动转 `$...$`（`delimited` 标志，2026-08-02 修复）；如发现仍残留 `\(` / `\)`，说明脚本版本过旧或页面结构特殊，逐条转 `$...$` 并记录。

## 4. 碎片化行内公式序列

每次通读时，检查仅被标点分隔的相邻行内公式片段，例如 `$x$-$y'$-$z''$`。脚本只能列出位置，**AI 助手必须读完整句**判断这些片段是否属于同一个数学对象：

1. 片段共同表示一个序列 / 坐标元组 / 映射 / 等式等单个数学对象 → 合并为一个公式
2. 有 `or` / `and` 等散文连接词分隔不同对象 → 保持分离
3. 连接符按语义选择：
   - 真减法 → 公式内的数学减号：`$x-y$`
   - 具名序列的分隔符（非减法）→ 公式内的 `\text{-}`：`$x\text{-}y$`
4. 每个候选与判断结论都写进轮次清单（包括**决定不改**的候选）
5. **绝不**用正则或自动替换做这种语义判断，只做逐条人工核对的精确编辑

示例（Tait–Bryan 旋转轴序列）：

| 原文 | 修复 | 理由 |
|------|------|------|
| `$x$-$y'$-$z''$` | `$x\text{-}y'\text{-}z''$` | 一个固有轴序列，连字符是分隔符 |
| `$x$-$y'$-$z''$ ... or $z$-$y$-$x$` | `$x\text{-}y'\text{-}z''$ ... or $z\text{-}y\text{-}x$` | `or` 是散文连接词，两个序列保持独立 |

收尾验证时确认：每个碎片化候选都经 AI 助手复核，每个合并后的序列使用单个 `$...$` 块。
